# README – randPedPCA Clustering Analysis
## South African Boerperd

## Purpose

This analysis was used to identify broad pedigree-based clusters in the South African Boerperd using the principal component scores generated by `randPedPCA`.

See the full script `Pedigree visualization using randPedPCA.R`

The aim was to determine whether animals grouped into major pedigree-structure clusters and whether the selected number of clusters was stable when different numbers of principal components were used.

---

## Input data

The clustering analysis used the centred pedigree PCA scores generated from the complete loop-resolved South African Boerperd pedigree.

The pedigree PCA was produced with `randPedPCA`, and the resulting PC scores were then used for clustering.

---

## Clustering method

Clustering was performed in R using:

```r
adegenet::find.clusters()
```

The analysis used:

- K-means clustering;
- BIC to compare alternative values of K;
- `n.start = 100`; and
- a maximum of 20 candidate clusters.

The clustering was performed on the pedigree PC scores rather than on SNP genotype data.

---

## Sensitivity analysis

Because the clustering result can depend on how many PCs are retained, the analysis was repeated using:

- 5 PCs
- 10 PCs
- 15 PCs
- 20 PCs

The candidate cluster numbers were:

| PCs used | Candidate K |
|---:|---:|
| 5 | 6 |
| 10 | 2 |
| 15 | 2 |
| 20 | 2 |

The result was therefore stable when 10, 15 or 20 PCs were used.

Using only 5 PCs produced a different solution of `K = 6`.

---

## Main clustering solution

The primary broad-scale clustering solution was:

```text
K = 2
```

For the main clustering analysis, **10 PCs** were retained.

The final settings were therefore:

```r
n_pc_cluster <- 10
final_k <- 2
```

and the final cluster assignment was obtained using:

```r
set.seed(1973)

final_clusters <- adegenet::find.clusters(
  x = cluster_matrix,
  n.pca = n_pc_cluster,
  n.clust = final_k,
  method = "kmeans",
  n.start = 100,
  center = FALSE,
  scale = FALSE
)
```

---

## BIC interpretation

For the 10-PC analysis, BIC decreased as K increased and did not show a clear internal minimum.

However, the largest reduction in BIC occurred between:

```text
K = 1 → K = 2
```

Because BIC continued to decline toward the upper end of the tested range, the largest tested K was not automatically treated as the biologically correct solution.

Instead, `K = 2` was retained as the main broad-scale grouping because it was repeatedly recovered when 10, 15 and 20 PCs were used.

Higher K values may represent finer subdivision within those broader pedigree groups.

---

## Interpretation

The clusters represent **patterns of pedigree structure**.

They should not automatically be interpreted as:

- separate breeds;
- fixed biological populations; or
- exactly two historical bloodlines.

The cluster assignments should be interpreted together with:

- the randPedPCA scatter plots;
- birth year;
- known pedigree history;
- family or bloodline information;
- breeder/stud information where available.

---

## Main outputs to keep

- randPedPCA PC-score file
- BIC values
- sensitivity results for 5, 10, 15 and 20 PCs
- final K = 2 cluster assignments
- PCA plot coloured by cluster
- R script used for clustering

---

## Short Methods description

Pedigree-based population structure was investigated by applying K-means clustering to principal component scores obtained from the centred randPedPCA analysis. Clustering was performed using `adegenet::find.clusters()`, and BIC was examined across alternative numbers of clusters. Sensitivity to the number of retained pedigree PCs was evaluated using 5, 10, 15 and 20 PCs. Candidate solutions were K = 6, 2, 2 and 2, respectively. Because K = 2 was recovered consistently when 10–20 PCs were retained, 10 PCs and K = 2 were used for the primary broad-scale clustering analysis.

---

## Key point

> The main result was a stable broad-scale `K = 2` pedigree clustering solution when 10, 15 or 20 PCs were used.

This should be interpreted as evidence of broad pedigree structure, not as proof that only two biological lineages exist in the South African Boerperd.
